The entry is exactly one emoji:

> 🫶

Heart hands — the warmest gesture a stranger can send without a word:
two hands shaping a heart, the universal sign for "thank you, I
appreciate you, you're welcome here". Kind and friendly at first glance
with no context needed, read the same way by a stranger of any age or
background — no irony, no in-joke, no sarcasm, no flirtation. It feels
chosen rather than default: not the first smiley that comes to mind, but
a deliberate little gesture, while staying instantly readable. And it is
right for a stranger precisely because it is a gesture, not an embrace
and not a kiss: warm without intimacy.
